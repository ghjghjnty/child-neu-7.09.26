# Артёмка (Artemka Audio Therapy Player)

> Специализированный медицинский терапевтический аудиоплеер со светофором, фабулами `.flac`, БРТ `.mp3`, протоколом 120-минутного отдыха и автоматическим курсом 5/2.

## 🌟 Ключевые возможности

1. **Двойная визуальная метафора «Светофор»**:
   - **Левый светофор (Фабулы)**: последовательные терапевтические сигналы Красный $\rightarrow$ Жёлтый $\rightarrow$ Зелёный.
   - **Правый светофор (Пешеходный БРТ)**: разрешающий зелёный индикатор («Поехали») для запуска сессии биорезонансной терапии.
2. **Строгие медицинские временные протоколы**:
   - Автоматический **таймер отдыха 2 часа (120 минут)** между фабулой и БРТ, а также между этапами светофора.
   - **Ночной спящий режим до 04:00 утра** после окончания зелёной фазы с защитой от случайного ночного включения.
3. **Календарный курс «5/2»**:
   - 5 рабочих дней терапии подряд с последующими 2 днями физиологического отдыха (выходные).
   - Учёт текущего дня и общего прогресса курса с возможностью настройки.
4. **Режимы терапевтического воспроизведения**:
   - **«По треку»**: обычное прослушивание аудиозаписи без повторений.
   - **«Д»**: детский 20-минутный режим для фабул.
   - **«1Брт»**: непрерывный 20-минутный цикл выбранного трека БРТ.
   - **«4Брт»**: кольцевая ротация треков (1 $\rightarrow$ 2 $\rightarrow$ 3 $\rightarrow$ 4 $\rightarrow$ 1...) с мягкой отсечкой (при истечении 20 минут активный трек доигрывает до конца без обрыва на полуслове).
5. **Дискретное стереозвучание (Discrete Stereo Balance)**:
   - Левый и правый каналы воспроизводятся строго независимо без суммирования в моно, сохраняя бинауральный терапевтический эффект.
6. **Офлайн-хранилище IndexedDB**:
   - Аудиофайлы сохраняются прямо на устройстве пользователя и доступны без доступа к сети.

## 🛠 Технологический стек

- **Фреймворк**: React 19 + TypeScript
- **Сборщик**: Vite 6
- **Стилизация**: Tailwind CSS v4 + Motion
- **Хранилище**: IndexedDB (API структурированного хранения файлов и прогресса)
- **Мобильная платформа**: Capacitor 8 (поддержка Android, фоновые локальные уведомления `@capacitor/local-notifications`)
- **Иконки**: Lucide React

## 🚀 Быстрый старт (Local Development)

### Требования
- Node.js 18+ или 20+
- npm, yarn, pnpm или bun

### Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/artemka-player.git
   cd artemka-player
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   ```

3. **Запустите локальный сервер разработки**:
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу `http://localhost:3000`.

4. **Проверка типов (Lint)**:
   ```bash
   npm run lint
   ```

5. **Сборка для продакшена**:
   ```bash
   npm run build
   ```
   Скомпилированные статические файлы будут сохранены в папку `dist/`.

## 📱 Сборка мобильного приложения Android (Capacitor)

Для запуска или сборки APK-файла через Android Studio:

```bash
# 1. Собрать веб-версию
npm run build

# 2. Синхронизировать веб-билд с Android-проектом
npx cap sync android

# 3. Открыть проект в Android Studio
npx cap open android
```

В Android Studio выберите **Build $\rightarrow$ Build Bundle(s) / APK(s) $\rightarrow$ Build APK(s)**.

## 📂 Структура проекта

```text
├── android/                 # Нативный Android-проект (Capacitor)
├── public/                  # Статические ресурсы, значки и манифест
├── src/

│   ├── components/          # React-компоненты:

│   │   ├── CalendarModal.tsx# Модальное окно курса 5/2
│   │   └── ...
│   ├── services/            # Сервисы таймеров и локальных уведомлений
│   ├── utils/               # Аудиосинтезатор, IndexedDB-хранилище, middleware

├── USER_MANUAL.md           # Подробная инструкция пользователя
├── package.json
└── vite.config.ts
```
